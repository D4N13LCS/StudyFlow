# StudyFlow 📚

O **StudyFlow** é uma aplicação desenvolvida para auxiliar estudantes na organização da vida acadêmica.

A proposta do projeto é reunir, em um único lugar, informações importantes da rotina de estudos, facilitando o acompanhamento de disciplinas, tarefas e compromissos acadêmicos.

## ✨ Funcionalidades

Atualmente, o projeto conta com:

- 📊 **Dashboard** com uma visão geral da rotina acadêmica
- 📚 **Disciplinas** para organização das matérias
- ✅ **Tarefas** para acompanhar atividades e prazos
- 📅 **Calendário** para visualizar compromissos acadêmicos
- 👤 **Perfil acadêmico** com informações do estudante
- 📝 **Detalhes das tarefas** para consultar e gerenciar atividades
- 📱 Interface adaptada para diferentes tamanhos de tela

## 🎯 Objetivo

O objetivo do StudyFlow é oferecer uma experiência simples e organizada para estudantes acompanharem suas atividades acadêmicas e terem uma visão mais clara da sua rotina.

O projeto também serve como uma oportunidade para aplicar conceitos de desenvolvimento de aplicações mobile e interfaces responsivas.

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando principalmente:

- React Native
- Expo
- Expo Router
- TypeScript

## 🚀 Executando o projeto

1. Instale as dependências

   ```bash
   npm install
   ```

2. Execute o app

   ```bash
   npx expo start
   ```
